# Repository contracts

This is the public collection of multiple independent program projects.
Keep each program's source, policies, demonstrations, evidence and reports together.
Read the program's current official rules and its local README before changing it.
A public repository commit does not submit a contest entry or a security report.
Never commit confidential vulnerability evidence, credentials, personal identity
information, payment documents, local environments or downloaded model binaries.
Only real submission confirmations and confirmed payment evidence establish those
milestones; a reward advertisement or passing local test does not.
Follow the license and verification commands of each individual project.
