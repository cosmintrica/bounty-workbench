# Bounty Workbench

A shared workspace for open-source challenge projects, reproducible demonstrations,
and public opportunity research. Each program gets its own folder. New projects
will be added here rather than creating a separate repository for every entry.

validation or revenue is claimed.

## Working agreements

- Check current program rules, actual funding and task availability before implementing.
- Keep source, policy notes, demonstrations, evidence and reports together by program.
- Distinguish a prepared project, a public release, a submitted entry, an award and a received payment.
- Respect program AI rules and disclose AI assistance. Current Subcheck materials were produced with OpenAI Codex.
- Keep confidential vulnerability evidence, private disclosure reports, credentials,
  identity documents and payment records outside this public repository.
- Preserve negative results and known limitations; do not label hypotheses as confirmed vulnerabilities.
